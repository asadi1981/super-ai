# SUPER AI — نسخه اولیه (MVP)

این نسخه یک وب‌اپ واکنش‌گرا و قابل نصب روی اندروید (PWA) است.

## امکانات فعلی
- رابط فارسی و راست‌چین برای موبایل و دسکتاپ
- گفت‌وگوی متنی با APIهای سازگار با قالب OpenAI Chat Completions
- ذخیره تاریخچه و یادداشت‌ها در مرورگر
- استودیو تولید سناریوی محتوای کوتاه با کمک مدل متصل
- خواندن فایل‌های متنی و ارسال متن برای تحلیل
- ورودی صوتی در مرورگرهای پشتیبانی‌شده
- پوسته آفلاین و کش فایل‌های برنامه

## اجرای محلی
به‌دلیل محدودیت Service Worker، برنامه را از طریق یک وب‌سرور اجرا کنید، نه با بازکردن مستقیم فایل:
```bash
python -m http.server 8000
```
سپس در همان دستگاه به `http://localhost:8000` بروید.

## نصب روی اندروید
1. برنامه را روی یک میزبان HTTPS منتشر کنید.
2. با Chrome اندروید نشانی برنامه را باز کنید.
3. منوی سه‌نقطه را بزنید و «افزودن به صفحه اصلی» یا «نصب برنامه» را انتخاب کنید.

## موتور چندمدلی در نسخه 1.1
- اتصال مستقیم به Ollama با مسیر `/api/chat` برای مدل محلی
- اتصال به سرویس‌های آنلاین سازگار با مسیر `/chat/completions`
- انتخاب موتور از داخل تنظیمات بدون تغییر کد
- تست اتصال از داخل برنامه

## راه‌اندازی رایگان موتور محلی با Ollama
1. روی رایانه‌ای که قرار است مدل را اجرا کند، Ollama را از `https://ollama.com` نصب کن.
2. ترمینال/Command Prompt را باز کن و یک مدل سبک را دریافت کن، مثلاً:
   ```bash
   ollama run qwen2.5:3b
   ```
   یا `ollama run llama3.2:3b`. انتخاب مدل به RAM، فضای ذخیره‌سازی و توان پردازنده بستگی دارد.
3. مطمئن شو سرویس Ollama در حال اجراست. آدرس پیش‌فرض آن `http://localhost:11434` است.
4. اگر برنامه روی همان رایانه اجرا می‌شود، در تنظیمات SUPER AI موتور «Ollama» و نشانی بالا را وارد کن؛ نام مدل باید دقیقاً با مدلی که نصب کرده‌ای یکی باشد.
5. اگر با گوشی به مدل رایانه وصل می‌شوی، گوشی و رایانه باید روی یک Wi‑Fi باشند. به‌جای localhost، IP محلی رایانه را وارد کن؛ برای مثال `http://192.168.1.10:11434`. پیکربندی دسترسی شبکه و CORS در Ollama و فایروال رایانه لازم است. این آدرس نمونه است و IP واقعی را باید از تنظیمات شبکه رایانه پیدا کنی.
6. دکمه «آزمایش اتصال» را بزن.

نکته: Ollama و مدل‌های متن‌باز معمولاً بدون هزینه مجوز/API قابل استفاده‌اند، اما رایانه، برق، اینترنت اولیه برای دانلود مدل و فضای دیسک هزینه/منابع خودشان را دارند. اجرای مدل روی گوشی اندروید به روش و اپ سازگار جداگانه نیاز دارد؛ این نسخه، مدل را مستقیماً داخل مرورگر موبایل اجرا نمی‌کند.

## اتصال هوش مصنوعی آنلاین
در تنظیمات اتصال:
- API Base: نشانی پایه ارائه‌دهنده که مسیر `/chat/completions` را پشتیبانی کند.
- Model: شناسه مدل ارائه‌دهنده.
- API Key: کلید دسترسی.

در حالت سرویس آنلاین، این برنامه در نسخه آزمایشی کلید را در localStorage مرورگر نگه می‌دارد و درخواست را مستقیم از مرورگر ارسال می‌کند. این روش برای محصول عمومی/چندکاربره امن نیست؛ علاوه بر آن، سرویس باید CORS مرورگر را مجاز کند. برای نسخه تولیدی، کلید باید روی سرور نگهداری شود و برنامه از Backend امن استفاده کند.

## واقعیت حالت آفلاین
آفلاین بودن فعلی یعنی پوسته برنامه، تاریخچه و یادداشت‌ها در دسترس می‌مانند. پاسخ‌گویی زبانی پیشرفته در حالت آفلاین به مدل محلی نیاز دارد که روی سخت‌افزار سازگار اجرا شود. Service Worker به‌تنهایی مدل زبانی ایجاد نمی‌کند.

## نقشه راه
1. Backend امن و مدیریت کلیدها
2. اتصال مدل محلی از طریق Ollama یا موتور سازگار
3. جست‌وجوی وب با منبع و ارجاع
4. تولید تصویر/ویدیو از طریق ارائه‌دهنده‌های قابل انتخاب
5. حافظه قابل جست‌وجو و پایگاه داده همگام‌سازی‌شده
6. مدیریت ابزارها، مجوزها و عامل‌های چندمرحله‌ای
7. بسته‌بندی اندروید با Capacitor در صورت نیاز به قابلیت‌های بومی

## امنیت و عیب‌یابی
- خطای CORS: دسترسی مبدأ وب‌اپ را در پیکربندی سرویس مجاز کن؛ این مورد از سمت مرورگر قابل دور زدن امن نیست.
- خطای Failed to fetch: آدرس، روشن بودن Ollama، شبکه محلی و فایروال را بررسی کن.
- خطای model not found: نام مدل را دقیقاً مطابق خروجی `ollama list` وارد کن.
- برای دسترسی از بیرون شبکه خانگی، Ollama را مستقیماً در اینترنت منتشر نکن؛ از VPN خصوصی یا Backend دارای احراز هویت و TLS استفاده کن.

## محدودیت‌های نسخه فعلی
- تولید تصویر/ویدیو مستقیماً پیاده‌سازی نشده؛ اتصال‌دهنده لازم دارد.
- جست‌وجوی زنده وب هنوز اضافه نشده.
- ذخیره‌سازی محلی وابسته به مرورگر و همان دستگاه است.
- از داده‌های حساس در این نسخه آزمایشی استفاده نکنید.
