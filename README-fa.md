# SUPER AI — نسخه اندروید-محور با درگاه امن

## وضعیت این نسخه
- رابط وب فارسی و واکنش‌گرا
- تاریخچه گفتگو و یادداشت‌ها در مرورگر
- ارسال پیام به درگاه امن Cloudflare Worker
- مدل آنلاین پیش‌فرض: `openrouter/free` (مدل رایگان در دسترس؛ انتخاب مدل واقعی تابع دسترس‌پذیری OpenRouter است)
- پوسته PWA و کش فایل‌های رابط
- کلید API در مرورگر یا GitHub قرار نمی‌گیرد

## ۱) انتشار فایل‌های سایت در GitHub
تمام محتویات این پوشه را در ریشه مخزن `asadi1981/super-ai` آپلود و Commit کن؛ در صورت درخواست، فایل‌های قبلی هم‌نام را جایگزین کن. مطمئن شو `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js` همگی در ریشه باشند.

## ۲) ساخت درگاه امن Cloudflare Worker
1. در گوشی به https://dash.cloudflare.com برو و یک حساب رایگان بساز/وارد شو.
2. از Workers & Pages گزینه Create ثم Worker بساز و نام `super-ai-gateway` بده.
3. در Quick Edit کد فایل `worker/index.js` را کامل جایگزین کد پیش‌فرض کن و Deploy بزن.
4. در Settings > Variables and Secrets یک Secret با نام `OPENROUTER_API_KEY` بساز و کلید API خودت را در آن قرار بده. این کلید را در GitHub، فایل‌ها یا چت منتشر نکن.
5. در بخش Variables مقدار `SITE_ORIGIN` را `https://asadi1981.github.io` و `DEFAULT_MODEL` را `openrouter/free` قرار بده. پس از تغییر، Deploy مجدد.
6. آدرس Worker معمولاً شبیه `https://super-ai-gateway.YOUR-SUBDOMAIN.workers.dev` است.

## ۳) دریافت کلید ارائه‌دهنده
1. به https://openrouter.ai برو و حساب بساز.
2. در بخش Keys یک کلید بساز. برای استفاده از مدل‌های رایگان، اعتبار خریداری‌شده لزوماً لازم نیست اما مدل‌های رایگان سهمیه، محدودیت و احتمال ازدحام دارند و تضمین دائمی ندارند.
3. کلید را فقط در Cloudflare به‌عنوان Secret با نام `OPENROUTER_API_KEY` ذخیره کن.

## ۴) اتصال سایت به Worker
1. سایت `https://asadi1981.github.io/super-ai/` را باز کن.
2. منو > تنظیمات اتصال.
3. موتور را روی «درگاه آنلاین امن» قرار بده.
4. نشانی سرویس را با آدرس Worker خودت جایگزین کن؛ فقط دامنه Worker را وارد کن، بدون `/api/chat`.
5. نام مدل را `openrouter/free` بگذار.
6. ذخیره تنظیمات و سپس آزمایش اتصال را بزن.
7. به صفحه گفتگو برگرد و پیام آزمایشی ارسال کن.

## نکته امنیتی و هزینه
- Cloudflare Workers و OpenRouter ممکن است طرح رایگان و محدودیت مصرف داشته باشند؛ سقف‌ها قابل تغییرند و استفاده رایگان نامحدود نیست.
- این Worker یک نمونه شروع است. محدودسازی Origin به‌تنهایی احراز هویت یا محافظت کامل در برابر سوءاستفاده نیست. قبل از استفاده عمومی، Rate Limiting/Turnstile یا احراز هویت اضافه کن و مصرف را پایش کن.
- کلید API فقط در Secret سرور ذخیره شود.

## حالت آفلاین
این نسخه در حالت آفلاین رابط، تاریخچه و یادداشت‌ها را نگه می‌دارد؛ پاسخ زبانی هوشمند آفلاین هنوز به runtime مدل محلی اندروید نیاز دارد. برای فعال‌سازی آن باید یک برنامه/موتور سازگار با مدل محلی روی گوشی نصب و رابط محلی امن آن بررسی شود. مرورگر به‌تنهایی با کش PWA مدل زبانی اجرا نمی‌کند.
