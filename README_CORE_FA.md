# شروع هسته SUPER AI (آزمایشی)

این پوشه نخستین اسکلت ماژولار هسته است و هنوز محصول اجرایی کامل نیست.

## نیازمندی
- Python 3.8 یا جدیدتر
- فقط کتابخانه استاندارد Python در این مرحله

## اجرای آزمون‌ها
از ریشه مخزن اجرا شود:

```bat
python -m unittest discover -s tests -v
```

## ماژول‌ها
- `core/contracts.py`: قراردادهای مدل و ابزار
- `core/policy.py`: سیاست دسترسی fail-closed
- `core/safe_files.py`: عملیات فایل محدود به workspace
- `core/audit.py`: ثبت رویداد JSONL
- `core/backup.py`: snapshot و restore با SHA-256

## محدودیت‌های فعلی
- هنوز هیچ مدل GGUF یا runtime به این هسته متصل نشده است.
- اجرای کد تولیدی، ترمینال، نصب وابستگی و کنترل برنامه‌های ثالث عمداً پیاده‌سازی نشده‌اند.
- این نسخه باید ابتدا روی Windows 7 و Python 3.8 آزمایش شود.
- سیاست دسترسی در این مرحله پایه است و جایگزین sandbox سیستم‌عامل یا حساب کاربری محدود نیست.
