## B. آزمون‌های Windows 7
محیط هدف: Windows 7 SP1 x64، Pentium G2020، RAM 4GB، Python 3.8.10.
- WIN-001: نصب/اجرای برنامه بدون اتصال اینترنت.
- WIN-002: اجرای مدل GGUF آزمایشی؛ ثبت RAM پیش از بارگذاری و در زمان تولید.
- WIN-003: 10 درخواست فارسی متوالی؛ ثبت میانگین و بیشینه زمان پاسخ و خطا.
- WIN-004: 10 درخواست کوتاه کدنویسی؛ بررسی syntax و اجرای تست مستقل.
- WIN-005: خروج و اجرای مجدد؛ حفظ تنظیمات و گفتگوهای انتخاب‌شده.
- WIN-006: جابه‌جایی کل پوشه برنامه به درایو دیگر؛ مسیرها نباید به مسیر مطلق قبلی وابسته باشند.
- WIN-007: قطع شبکه در زمان اجرا؛ قابلیت‌های محلی نباید از کار بیفتند.
- WIN-008: کمبود RAM؛ برنامه باید خطای کنترل‌شده بدهد، نه crash یا آسیب داده.

## D. آزمون‌های Programmer
- PROG-001: ساخت پروژه نمونه Python در workspace خالی.
- PROG-002: تولید فایل دارای خطای syntax؛ verifier باید آن را تشخیص دهد.
- PROG-003: اصلاح خطا و اجرای مجدد آزمون.
- PROG-004: نمایش diff پیش و پس از تغییر.

- PROG-006: تولید گزارش build/test شامل دستور، زمان، exit code و خلاصه خروجی.

## E. قواعد ثبت نتیجه
هر آزمون یکی از وضعیت‌های زیر را می‌گیرد:
- PASS: روی محیط هدف اجرا و نتیجه مستند شده است.
- FAIL: اجرا شده و معیار را رد کرده است.
- BLOCKED: پیش‌نیاز یا دسترسی موجود نبوده است.
- NOT RUN: هنوز اجرا نشده است.
گزارش باید نسخه برنامه، نسخه مدل، checksum مدل، سیستم‌عامل، سخت‌افزار، تنظیمات و log مرتبط را ثبت کند. نتیجه یک دستگاه به دستگاه دیگر تعمیم داده نمی‌شود.
