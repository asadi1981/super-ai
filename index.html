تنظیمات اتصال

برای پاسخ هوشمند آنلاین، یک سرویس سازگار با API استاندارد Chat Completions وارد کن.

برای استفاده از مدل محلی، Ollama باید روی رایانه یا دستگاه سازگار نصب و در حال اجرا باشد.

Ollama روی رایانه رایگان است، اما به فضای دیسک و RAM کافی نیاز دارد. برای اتصال گوشی به Ollama روی رایانه، نشانی IP محلی رایانه را وارد کن و دسترسی شبکه/CORS را در Ollama تنظیم کن. هرگز Ollama را بدون محافظت مستقیماً روی اینترنت عمومی باز نکن.

مدل محلی و اجرای آفلاین

پس از دانلود مدل در Ollama، اجرای گفت‌وگو روی همان رایانه می‌تواند بدون اینترنت انجام شود. اگر با گوشی وارد می‌شوی، مدل معمولاً روی رایانه اجرا می‌شود و گوشی از طریق Wi‑Fi به آن وصل می‌شود. خود گوشی A70 برای مدل‌های بزرگ مناسب نیست.

نمونه مدل‌های سبک برای شروع: qwen2.5:3b یا llama3.2:3b (نیازمند بررسی سازگاری و فضای کافی).
